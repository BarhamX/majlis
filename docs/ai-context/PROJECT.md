# AI Context: Project

## Name

Majlis

## Product

Android-first Flutter mobile game with a .NET backend.

## One-Line Description

Majlis is a daily Arab culture challenge game that recreates the feeling of a traditional majlis through short puzzles, proverbs, stories, discussion prompts, streaks, and friendly social competition.

## Product Pillars

1. Daily ritual.
2. Arab cultural knowledge.
3. Warm social interaction.
4. Friendly competition.
5. Cultural authenticity.
6. Safe moderated community.
7. Shareable moments.

## MVP

Playable Daily Majlis:

- Login/profile.
- Today's challenge.
- Answer submission.
- Result/explanation.
- Streak/XP.
- Share card.
- Daily discussion.
- Basic moderation/reporting.

## Do Not Build Yet

- Full courses.
- iOS.
- AI-generated content.
- Open public social network.
- Paid subscription.
- School dashboards.
- Advanced audio.
