# Majlis User Stories

## Epic 1: Foundation and Authentication

- As a new user, I want to create an account so that my streak and progress are saved.
- As a user, I want to choose my display name so that others can recognize me in Majlis discussions.
- As a user, I want to select my region or dialect preference so that content can become more relevant over time.
- As a user, I want secure account recovery, session revocation, and account deletion so that I control access to my data.
- As a minor user, I want private defaults and no public ranking so that the app minimizes my exposure.

## Epic 2: Daily Majlis Content

- As a user, I want to see today's Majlis so that I have one clear cultural challenge to complete.
- As a user, I want the daily content to be short so that I can complete it during a break.
- As an admin, I want to schedule Daily Majlis content so that the app can publish without code changes.

## Epic 3: Challenge and Scoring

- As a user, I want to answer a multiple-choice cultural challenge so that I can test my knowledge quickly.
- As a user, I want immediate feedback so that I understand whether I was right.
- As a user, I want a short explanation so that I learn the meaning behind the answer.
- As a user, I want XP and streak progress so that I feel rewarded for returning daily.
- As a user, I want duplicate or retried submissions to preserve one result so that network failures cannot change my score.

## Epic 4: Social Majlis

- As a user, I want to answer a daily discussion question so that I can share my perspective.
- As a user, I want to read other responses so that the app feels like a real majlis.
- As a user, I want to react to responses so that I can participate lightly.
- As a user, I want to report inappropriate responses so that the community stays respectful.
- As a user, I want pending-review feedback, blocking, deletion, and an appeal path so that I can participate safely and understand moderation outcomes.

## Epic 5: Sharing and Growth

- As a user, I want to share my result card so that I can challenge friends.
- As a recipient, I want the shared card to make me curious without spoiling the answer.
- As a user, I want to share a safe link with family/friends so that they can play the same daily challenge.
- As a user, I want a privacy-safe leaderboard so that comparison feels social without exposing private activity.
- As a user, I want to control daily reminders so that Majlis supports my routine without pressuring me.

Private Family Majlis membership, group discussion, and group leaderboards are post-V1 stories.

## Epic 6: Admin and Content Operations

- As an admin, I want to create proverbs, stories, and questions so that I can build future Daily Majlis content.
- As an admin, I want to tag content by region and difficulty so that content can be curated intelligently.
- As an admin, I want to review reported comments so that community safety is maintained.
- As an admin, I want to publish, correct, or unpublish reviewed content without a code deployment.
- As an operator, I want health, logging, analytics, backup, and recovery procedures so that Majlis can run reliably in production.
- As a content reviewer, I want immutable revisions, required Arabic, and source validation so that published cultural material is traceable and accurate.
