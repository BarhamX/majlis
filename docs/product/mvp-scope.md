# Majlis MVP Scope

## MVP Name

Playable Daily Majlis

## MVP Outcome

Validate whether users will return daily to answer a short Arab cultural challenge, learn a micro-story/proverb, and share or discuss it.

## In Scope

- Android Flutter app.
- .NET backend.
- User account/profile.
- Daily challenge.
- Result and explanation.
- Streak and XP.
- Shareable result card.
- Daily discussion question.
- Basic comments.
- Report comment.
- Admin content creation/scheduling through API or simple internal tool.
- Basic analytics events.

## Out of Scope

- iOS app.
- Full web app.
- Paid subscription implementation.
- School dashboard.
- Advanced audio storytelling.
- AI content generation.
- Open public groups.
- Direct messages.
- Real-money prizes.

## MVP Quality Bar

- User understands what to do in less than 10 seconds.
- Challenge completion takes less than 1 minute.
- Full daily loop takes 1-3 minutes.
- Share card is visually attractive enough to post.
- Community response has reporting before public release.
- Content can be changed without app release.
